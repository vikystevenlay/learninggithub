# Git Tutorial in CourseNet
This is repository of `Git Tutorials` in CourseNet.


In short, you can just follow below instructions.
1. First, change the config to your GitHub account.
```
git config --global user.name "<username>"
git config --global user.email "<email>"

```
2. Initialize
```
git init
```

3. If you have many Git account and want to change the one that you want to use, please hit this command
```
gh auth login
```
